# Hunger Games em Berlim

Página de roteiro com as locações de Hunger Games em Berlim: foto do lugar hoje, cena do filme, fatos e curiosidades, se dá pra entrar ou só ver por fora, botões pro mapa e um roteiro de Reels (~1:30) com falas extras.

**Página:** https://ro2342.github.io/hunger-games-berlim/

É um HTML único (`index.html`), sem dependências, com as imagens embutidas.

## Créditos
- Fotos dos lugares: Wikimedia Commons. Autoria e licença na legenda de cada foto.
- Cenas do filme: imagens de divulgação de Leonine Studios e Studiocanal, via Medienboard Berlin-Brandenburg, usadas só para ilustrar as locações.
- Os fatos vêm de fontes públicas. Confira horários e regras de entrada antes de ir.
